\section{Feature Calculation Description}

We used two feature types to train our models, image metric features and cell metric features:

\subsection{Image Metric Features}

The image metric features contained a count of pixels that were over-exposed, or had a value of 255 when converted to greyscale. We also included an array representing a histogram of pixel intensities. The number of bins was variable and testing on this parameter is discussed later. We chose these feature since we saw a large difference of pixel intensities between different groups pictures. This made us believe that a histogram of pixel intensities could predict accurately which group created the image.

\subsection{Cell Metric Features}

We had two cell metric features derived from an image segmentation of each photo. The image segmentation was conducted with the same code as the previous segmentation lab using my OpenCV code. See that write-up for more information. We took the count of cells found and the average size of these cells as features.

\subsection{Conversion to 1D Array}

To properly train a model on this, we need to convert these features into an array. We have 2 images per location that must be paired, so we take each image and turn it into an array of features and then append them together. This is then passed into the model when training or testing.\\

Unfortunately, the image segmentation is not particularly fast, and on the models for finding the group or magnification level, accuracy was not improved with the cell metric features. Thus, we used the short feature list (only the image metric features) for the group and magnification level models and then used all features for the treatment model.

\begin{figure}[H]

From this figure we can see that the TRANS image is significantly more important than the DAPI image, with only two of the DAPI features even being used. Note that this is with 10 bins for legibility, maximum performance is achieved with 256 bins. This histogram is quite similar, with the DAPI features not being used and the usage of the histogram being about uniform, however it would not be feasible to visualize.
